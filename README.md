# hitsmith

A lightweight hitsounding workstation for osu! mappers, written in Rust.

- One 7 MB exe, no runtime to install. Uses Windows' own fonts for Japanese/Chinese/Korean titles.
- No library scan: you open a `.osu` file yourself, so startup is instant.

## Using it

1. Drop a mapset (`.osz`), a mapset folder, or any difficulty (`.osu`) onto the window, or click **New project**.
   A `.osz` is unpacked into your osu! Songs folder, like osu! does. hitsmith creates the project and
   Normal / Whistle / Finish / Clap samples using the mapset's own sound files (or your skin's).
   If the timing difficulty is a hitsound difficulty, its hits are imported too.
2. Click the grid to place hits, or press a sample's key (Q/W/E/R by default) at the playhead.
3. Use the **Volume** lane to add volume points. **Export** writes a hitsound difficulty into the mapset folder.

Keyboard shortcuts follow the osu! editor (press **Keys** in the toolbar for the full list):

| Keys | Action |
|---|---|
| Space / C, X, Z / V | Play or pause, play from start, jump to first / last hit |
| Left / Right (Shift: 4x), mouse wheel | Step one snap tick, seek |
| Up / Down | Previous / next timing or volume point |
| Ctrl+wheel, Shift+1..9 | Change snap divisor |
| Alt+wheel | Zoom (over the timeline); overall volume (anywhere else) |
| Wheel over a volume slider or volume point | Change it 5% (Shift: 1% on points) |
| Ctrl+Up / Down | Playback speed (25% steps, Shift: 5%) |
| 1 / 2 | Select tool / Place tool |
| Sample keys (default Q / W / E / R) | Toggle a hit at the playhead on that sample; click a sample's key cap to change it |
| Ctrl+A / X / C / V / D, Delete, J / K | Select all, cut, copy, paste, clone, delete, nudge |
| Ctrl+drag a hit | Copy the selected hits to where you drop them |
| Drag a hit up / down | Move the selected hits to another sample (Ctrl: copy) |
| Double-click a hit | Select every hit of that sample |
| Double-click / right-click a bar on the ruler | Select its hits / select, repeat into the next bar, or clear |
| Ctrl+B, Ctrl+Shift+B, Ctrl+Left / Right | Add, remove, jump between bookmarks |
| Ctrl+Shift+P, Ctrl+I | Add / delete a volume point |
| Ctrl+Z / Y, Ctrl+S, Ctrl+N, Esc | Undo / redo, save, remove all hits, back |

**Themes:** the Theme menu has Light and Dark modes with 5 palettes each, including an osu!-style pink one.
Colours blend smoothly when you switch. Ctrl+T flips between light and dark.

Projects are saved automatically to `projects\` next to the exe (or `%APPDATA%\hitsmith` if that folder isn't writable).
Deleting a project moves it to the Recycle Bin.

## How export works

Every distinct set of sounds that plays at the same moment is mixed into one `normal-hitnormalN.wav`.
Each circle plays only its hitnormal, and green lines pick the sample index and volume. This reproduces
the arrangement exactly, regardless of skin or layering settings.

The game mode can be chosen in the Export window. For **osu!mania** the export is keysounded instead:
every sound is its own note naming its sound file (any file name works), sounds that play together go in
separate columns, and the key count is the most sounds that ever play at once (up to 10). Sound files from
outside the mapset are copied in. More than 10 at once falls back to the mixed method.

Safety rules:

- Sample indices the mapset already uses are skipped.
- An existing difficulty is never overwritten unless this app created it.
- Files from a previous export that are no longer needed are removed.
- What the app created is tracked in `.hitsmith-export.json` inside the mapset folder.

## Building

Needs Rust (`rustup`, toolchain `stable-x86_64-pc-windows-gnu`) and [WinLibs MinGW-w64](https://winlibs.com/)
extracted to `%USERPROFILE%\winlibs`. Then run:

```
build.cmd
cargo test
```

(`cargo test` needs the same PATH as `build.cmd` sets.) The logo and icons are generated by `python assets/make_logo.py`.
